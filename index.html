01
ARITHMETIC SEQUENCE

🔢 ลำดับเลขคณิต

ลำดับที่ผลต่างระหว่างพจน์ที่อยู่ติดกันมีค่าคงที่ เรียกว่า ผลต่างร่วม (d) เช่น 2, 5, 8, 11, 14 เพิ่มขึ้นครั้งละ 3

2+3 →5+3 →8+3 →11+3 →14
aₙ = a₁ + (n − 1)d

a₁ = พจน์แรก, n = ลำดับที่ของพจน์, d = ผลต่างร่วม

ตัวอย่าง ถ้า a₁ = 2 และ d = 3 จงหาพจน์ที่ 10
a₁₀ = 2 + (10 − 1)(3) = 29
💡 ทดลองคิด: 7, 11, 15, 19, … พจน์ที่ 6 เท่ากับเท่าใด?

ผลต่างร่วม d = 4 และ a₆ = 7 + 5(4) = 27

02
GEOMETRIC SEQUENCE

✨ ลำดับเรขาคณิต

ลำดับที่อัตราส่วนระหว่างพจน์ติดกันมีค่าคงที่ เรียกว่า อัตราส่วนร่วม (r) เช่น 3, 6, 12, 24, 48 แต่ละพจน์คูณ 2 จากพจน์ก่อนหน้า

3×2 →6×2 →12×2 →24×2 →48
aₙ = a₁ × r⁽ⁿ⁻¹⁾

สำหรับพจน์ก่อนหน้าที่ไม่เป็นศูนย์ อัตราส่วนร่วม r = aₙ₊₁ / aₙ

ตัวอย่าง 3, 6, 12, … จงหาพจน์ที่ 6
a₆ = 3 × 2⁵ = 96
💡 ทดลองคิด: 81, 27, 9, 3, … พจน์ถัดไปคืออะไร?

อัตราส่วนร่วม r = 1/3 ดังนั้นพจน์ถัดไปคือ 1

03
ARITHMETIC & GEOMETRIC SERIES

🧮 อนุกรมเลขคณิตและอนุกรมเรขาคณิต

อนุกรม คือผลบวกของพจน์ในลำดับ เช่น 2 + 5 + 8 + 11 + 14 = 40 ใช้สัญลักษณ์ Sₙ แทนผลบวก n พจน์แรก

อนุกรมเลขคณิต

Sₙ = n(a₁ + aₙ) / 2

เช่น 2 + 5 + 8 + 11 + 14
S₅ = 5(2 + 14)/2 = 40

อนุกรมเรขาคณิต

Sₙ = a₁(1 − rⁿ) / (1 − r)

ใช้เมื่อ r ≠ 1 เช่น 2 + 4 + 8 + 16
S₄ = 2(1 − 2⁴)/(1 − 2) = 30

ถ้า r = 1 จะได้ Sₙ = na₁

💡 ทดลองคิด: 1 + 3 + 9 + 27 เท่ากับเท่าใด?

เป็นอนุกรมเรขาคณิต a₁ = 1, r = 3, n = 4 ผลบวก S₄ = 40

04
INTEREST

🏦 ดอกเบี้ย

ดอกเบี้ยเป็นผลตอบแทนจากการฝากเงินหรือต้นทุนจากการกู้ยืม โดยแบ่งแนวคิดพื้นฐานเป็น ดอกเบี้ยอย่างง่าย และ ดอกเบี้ยทบต้น ซึ่งเกี่ยวข้องกับลำดับเรขาคณิต

ดอกเบี้ยอย่างง่าย

A = P(1 + it)

P = เงินต้น, i = อัตราดอกเบี้ยต่อปีในรูปทศนิยม, t = จำนวนปี

ดอกเบี้ยทบต้นรายปี

A = P(1 + i)ᵗ

เงินต้นรวมดอกเบี้ยของแต่ละปีจะกลายเป็นฐานคำนวณของปีต่อไป

ตัวอย่าง ฝากเงิน 1,000 บาท อัตราดอกเบี้ยทบต้น 5% ต่อปี เป็นเวลา 2 ปี
A = 1,000(1.05)² = 1,102.50 บาท
สมมติว่าอัตราคงที่ ไม่มีภาษีและค่าธรรมเนียม
05
TIME VALUE OF MONEY & ANNUITIES

💰 มูลค่าของเงินและค่างวด

มูลค่าของเงินตามเวลา หมายถึง เงินจำนวนเท่ากันในเวลาต่างกันอาจมีมูลค่าไม่เท่ากัน เพราะเงินสามารถสร้างผลตอบแทนได้ ส่วน ค่างวด คือการรับหรือจ่ายเงินจำนวนเท่า ๆ กันตามช่วงเวลาที่กำหนด

มูลค่าในอนาคต (FV)

FV = PV(1 + i)ⁿ

เช่น 1,000 บาทเติบโต 10% ต่อปี เป็น 2 ปี จะได้ 1,210 บาท

มูลค่าปัจจุบัน (PV)

PV = FV / (1 + i)ⁿ

มูลค่าปัจจุบันของเงิน 1,210 บาทที่จะได้รับอีก 2 ปี เมื่ออัตราคิดลด 10% คือ 1,000 บาท

ตัวอย่างค่างวดฝากปลายงวด ฝากปลายปี ปีละ 1,000 บาท เป็นเวลา 3 ปี อัตรา 10% ต่อปี
FV = 1,000[(1.10)³ − 1]/0.10 = 3,310 บาท
สูตรทั่วไป FV = R[(1 + i)ⁿ − 1]/i เมื่อ i ≠ 0 และฝากปลายงวด (ถ้า i = 0 จะได้ FV = Rn)
💡 คิดวิเคราะห์: เงิน 1,000 บาทวันนี้ กับอีก 2 ปี เหมือนกันหรือไม่?

หากนำเงินวันนี้ไปลงทุนที่ผลตอบแทน 10% ต่อปี เงิน 1,000 บาทวันนี้จะเพิ่มเป็น 1,210 บาทในอีก 2 ปี จึงมีมูลค่าตามเวลาต่างกัน ภายใต้สมมติฐานดังกล่าว

🔍 เปรียบเทียบลำดับทั้งสองชนิด

ประเด็นลำดับเลขคณิตลำดับเรขาคณิต
ความสัมพันธ์ของพจน์บวกผลต่างร่วม dคูณอัตราส่วนร่วม r
ตัวอย่าง2, 5, 8, 11, …2, 4, 8, 16, …

Thai + English

Solve math challenges to attack, cast skills, or defend. Each character acts in turns, so beginners have time to plan.

📘 วิธีเล่น / How to play และการทำงานของฟังก์ชัน
1. เลือกคำสั่ง / Choose an action

โจมตี (Attack) สร้างความเสียหาย 18; เวทมนตร์ (Skill) สร้าง 30 ใช้ MP 10; ป้องกัน (Defend) ลดความเสียหาย; ฟื้นฟู (Potion) เติม HP 25 และใช้ขวดยา 1 ขวด

2. ตอบโจทย์ / Solve a question

โจมตีและเวทมนตร์จะมีโจทย์ลำดับหรืออนุกรมให้เลือกตอบ ตอบถูกจึงโจมตีสำเร็จ หากผิด ศัตรูจะได้เทิร์นตอบโต้

3. เทิร์นศัตรู / Enemy turn

เมื่อผู้เล่นทำคำสั่งเสร็จ ศัตรูที่ยังมีชีวิตจะโจมตีกลับ ตรวจสอบ HP และเข้าสู่เทิร์นใหม่

4. ผลลัพธ์ / Outcome

ศัตรู HP เป็น 0 = ชนะ (Victory); ผู้เล่น HP เป็น 0 = แพ้ (Defeat) สามารถกดเริ่มใหม่ได้ทุกเมื่อ
